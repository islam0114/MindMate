======================================================
           MindMate Project - دليل التشغيل
======================================================

متطلبات التشغيل الأساسية:
1. Python (يفضل 3.10 أو أحدث)
2. Node.js (لإدارة واجهة Next.js)
3. ملف .env (يجب أن يحتوي على مفتاح Gemini API)

---

### الخطوة الأولى: إعداد الباك إند (FastAPI)
1. افتح Terminal في مجلد المشروع الرئيسي.
2. أنشئ بيئة افتراضية (Virtual Environment):
   python -m venv venv
   
3. فعل البيئة:
   - Windows: venv\Scripts\activate
   - Mac/Linux: source venv/bin/activate

4. ثبّت المكتبات:
   pip install -r requirements.txt

5. تأكد من وجود ملف .env في المجلد الرئيسي، ويحتوي على:
   GEMINI_API_KEY=YOUR_ACTUAL_API_KEY_HERE

6. شغل الخادم:
   python api.py

---

### الخطوة الثانية: إعداد الفرونت إند (Next.js)
1. افتح Terminal جديد في مجلد المشروع.
2. انتقل إلى مجلد الفرونت إند:
   cd mindmate-frontend

3. ثبّت المكتبات الخاصة بالواجهة:
   npm install

4. شغل الواجهة:
   npm run dev

---

### الخطوة الثالثة: الوصول للتطبيق
- بعد تشغيل الأمرين، افتح متصفحك وتوجه إلى:
  http://localhost:3000

ملاحظة: تأكد من بقاء نافذة الباك إند (api.py) تعمل في الخلفية ليتمكن التطبيق من إرسال واستقبال البيانات.
